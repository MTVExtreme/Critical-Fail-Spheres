# Changelog

All notable changes to this project will be documented in this file.

## [14.0.0] - 2026-10-20

- First Release
- Created the Critical Fail Spheres module for Foundry V14, with the 1.4.7 compendium content as its baseline.
- Added Foundry V14 compatibility and migration of existing `pf1spheres` compendium links; the original module is disabled after migration.
- Added Spheres of Guile talent support and an optional character-sheet tab for skill spheres, talent counts, and granted skill ranks.
